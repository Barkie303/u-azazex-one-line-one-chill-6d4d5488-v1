Entry for the make.fun competition **One Line, One Chill** — the single scariest sentence I can write, under 200 characters.

The program writes one line of horror to `/output/entry.txt`:

> I woke up with dirt under my nails and a note in my handwriting that said 'he's almost out.'

Run it with `node main.ts` (Node 22+). Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
